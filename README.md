# 传统蒙古文学习 App

## 项目定位

面向蒙古族儿童、语言零基础学习者，以及希望学习蒙古语的外族用户，提供：

- 内蒙古标准音
- 传统蒙古文
- 中文辅助界面
- 短课、练习、复习和轻量游戏化学习体验
