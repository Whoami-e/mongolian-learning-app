# 传统蒙古文学习 App 产品原型

## 1. 原型结论

原型暂定名：**竖文启蒙**

定位：

> 面向蒙古族儿童、零基础成人和外族学习者的传统蒙古文入门 App，采用内蒙古标准音和中文辅助界面。

设计原则：

- 不照抄多邻国的闯关地图、绿色主视觉、动物助手或任务形象。
- 以传统蒙古文的竖排阅读、字形变化和真人音频为核心体验。
- 所有传统蒙古文学习内容必须竖排展示；中文界面说明保持横排。
- 游戏化只做学习反馈，不让奖励系统压过语言学习。
- 儿童和成人共用内容，但界面密度、解释深度和题量不同。

## 2. 视觉方向

### 2.1 设计概念

**竖文学习手账**

App 的核心视觉不是“打怪通关”，而是一本随身学习手账。用户每天打开后看到今日字母、今日词汇、复习印章和学习札记。

### 2.2 记忆点

**竖排字形练习面板**

在课程页中，传统蒙古文以竖向主视觉展示。用户通过听音、识字、选择、补全来学习字形。

### 2.3 色彩

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 宣纸白 | `#F7F2E8` | 页面背景 |
| 墨黑 | `#20201D` | 主文字 |
| 湖蓝 | `#2C6E8F` | 主按钮、学习进度 |
| 朱砂 | `#C95B46` | 错误反馈、重点提示 |
| 金印 | `#D7A441` | 星星、徽章、完成态 |
| 松石 | `#3B7C6E` | 正确反馈、复习状态 |

### 2.4 字体建议

- 中文界面：苹方 / 思源黑体 / 系统无衬线
- 传统蒙古文：必须选用授权清晰、移动端显示稳定的蒙古文字体
- 数字和状态信息：系统等宽或半等宽字体

## 4. 核心用户路径

### 4.1 首次进入

```text
启动页
-> 选择学习身份
-> 选择学习目标
-> 下载首批离线课程
-> 学习首页
```

学习身份：

- 儿童
- 成人初学者
- 家长代管

学习目标：

- 每天 3 分钟
- 每天 5 分钟
- 每天 10 分钟

### 4.2 日常学习

```text
学习首页
-> 今日课程
-> 新内容展示
-> 听音
-> 练习题
-> 错题即时复习
-> 课程结果
-> 返回首页
```

### 4.3 错题复习

```text
复习页
-> 今日要复习
-> 混合题型
-> 掌握/仍需练习
-> 更新复习时间
```

## 5. 页面原型

以下以 390 x 844 手机屏幕为基准。

### 5.1 启动页

目的：

- 传达这是传统蒙古文学习工具
- 不使用动物形象或仿多邻国任务形象

布局：

```text
┌──────────────────────────┐
│                          │
│        竖文启蒙          │
│    传统蒙古文入门        │
│                          │
│      ᠠ                   │
│      ᠪ                   │
│      ᠮ                   │
│                          │
│      [ 开始学习 ]        │
│      已有进度，继续      │
│                          │
└──────────────────────────┘
```

说明：

- 中央使用竖向蒙古文字母列。
- 背景不使用卡通插画，用纸纹、细线和印章感建立风格。

### 5.2 身份选择页

目的：

- 区分儿童和成人体验
- 家长可代儿童设置学习时间

布局：

```text
┌──────────────────────────┐
│  谁来学习？              │
│                          │
│  ┌────────────────────┐  │
│  │ 儿童学习           │  │
│  │ 图片多，题目短     │  │
│  └────────────────────┘  │
│  ┌────────────────────┐  │
│  │ 成人初学           │  │
│  │ 解释更详细         │  │
│  └────────────────────┘  │
│  ┌────────────────────┐  │
│  │ 家长代管           │  │
│  │ 设置学习时间       │  │
│  └────────────────────┘  │
└──────────────────────────┘
```

### 5.3 学习首页

目的：

- 让用户立刻知道今天学什么
- 不做闯关地图，改成学习手账结构

布局：

```text
┌──────────────────────────┐
│  早上好                  │
│  今日 5 分钟             │
│                          │
│  ┌────────────────────┐  │
│  │ 今日新字           │  │
│  │    ᠠ               │  │
│  │  基础元音一        │  │
│  │  [ 开始 ]          │  │
│  └────────────────────┘  │
│                          │
│  第一单元：认识蒙古文    │
│  01 书写方向   已完成    │
│  02 基础元音   今天      │
│  03 基础元音   未开始    │
│                          │
│  学习  复习  词库  我的  │
└──────────────────────────┘
```

关键设计：

- 用纵向“今日新字”替代卡通任务。
- 课程列表像手账目录，不是路径闯关。
- 连续学习展示为“学习印章”，不突出排名。

### 5.4 字母课程页

目的：

- 聚焦字形、发音和位置变化

布局：

```text
┌──────────────────────────┐
│  基础元音一          2/6 │
│  ────────────────        │
│                          │
│        ᠠ                 │
│        ᠠ                 │
│        ᠠ                 │
│                          │
│  [ 播放发音 ]            │
│                          │
│  这个字母在词中会连写。  │
│                          │
│  独立  词首  词中  词尾  │
│  ᠠ     ᠠ     ᠠ     ᠠ     │
│                          │
│  [ 继续 ]                │
└──────────────────────────┘
```

交互：

- 点发音按钮播放真人音频。
- 点不同字形切换放大显示。
- 成人模式显示解释，儿童模式显示更少文字。

### 5.5 听音选字题

目的：

- 训练音到字的对应关系

布局：

```text
┌──────────────────────────┐
│  听一听，选出听到的字    │
│  ────────────────        │
│                          │
│       [  声音按钮  ]     │
│                          │
│  ┌──────┐ ┌──────┐       │
│  │  ᠠ   │ │  ᠡ   │       │
│  └──────┘ └──────┘       │
│  ┌──────┐                │
│  │  ᠣ   │                │
│  └──────┘                │
│                          │
│       [ 确认 ]           │
└──────────────────────────┘
```

状态：

- 未选择：确认按钮不可用
- 正确：选项变松石色，底部提示“读得对”
- 错误：选项变朱砂色，同时显示正确字

### 5.6 看图选词题

目的：

- 适合儿童建立词义关联

布局：

```text
┌──────────────────────────┐
│  这是什么？              │
│                          │
│  ┌────────────────────┐  │
│  │       图片区域      │  │
│  │       马/羊/书      │  │
│  └────────────────────┘  │
```

- 正式图片应是清楚可辨认的实物或扁平插图。
- 不用拟人化动物角色做任务助手。

## 7. 交互规则

### 音频

- 每道题只能同时播放一个音频。
- 切换题目时自动停止上一条音频。
- 发音按钮需要有播放中状态。

### 答题

- 选项点击后高亮。
- 未选择答案前不可确认。
- 答错后立即显示正确答案和简短原因。
- 答错题目自动进入本节课末尾复习。

### 复习

- 当天错题当天再次出现。
- 连续答对后延后复习。
- 多次答错的内容标记为重点。

## 8. 不做清单

第一版不做：

- 多邻国式曲线路径地图
- 绿色主视觉和相似按钮系统
- 动物导师、鸟类助手或类似任务形象
- 公开排行榜
- AI 语音评分
- 社交聊天
- 复杂家长后台

## 9. 原型验收标准

这版原型通过的标准：

- 首页能说明今天学什么
- 课程页能突出传统蒙古文竖排学习
- 练习题不依赖复杂讲解也能理解
- 错题反馈能帮助修正
- 词库和复习能承接课后学习
- 视觉上不会被误认为多邻国仿品
