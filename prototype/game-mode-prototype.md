# 传统蒙古文学习 App 游戏化原型

## 1. 设计边界

这版原型把学习机制调整为“强游戏化语言学习”：

- 课程路径
- 连续学习
- 经验值
- 红心生命
- 宝石奖励
- 每日任务
- 错题复活
- 单元宝箱
- 排行榜入口

硬性排版规则：

> 所有传统蒙古文学习内容必须竖排展示。中文说明、按钮和状态信息保持横排。

但不直接复制多邻国的：

- Logo
- 吉祥物
- 绿色主视觉
- 按钮样式
- 课程节点造型
- 原文案
- 插画角色和任务形象

原型名称暂定：**草原字母岛**

核心体验：

> 像玩一款轻量闯关游戏一样学习传统蒙古文，每天完成一小段课程，积累经验、保住连胜、复习错题。

## 2. 用户首页

首页改为课程路径模式。

顶部状态：

- 连续天数
- 红心数量
- 宝石数量
- 当前经验值

主体：

- 单元标题
- 曲线路径节点
- 当前课程高亮
- 已完成课程显示星级
- 锁定课程显示锁
- 宝箱节点显示奖励

底部导航：

- 学习
- 任务
- 练习
- 排行
- 我的

- 挑战

## 4. 游戏机制

### 4.1 红心生命

默认 5 颗红心。

- 答错 1 题扣 1 颗红心
- 红心为 0 时不能继续普通课程
- 可以通过复习错题恢复红心
- 儿童模式不建议强制付费或强广告恢复

### 4.2 经验值

完成课程获得经验值：

- 普通课程：10 XP
- 全对：额外 5 XP
- 单元挑战：20 XP
- 每日任务：额外 10 XP

### 4.3 连续学习

每天完成至少 1 节课，保持连续天数。

可加入：

- 连续 3 天奖励
- 连续 7 天奖励
- 连续保护卡

### 4.4 宝石

宝石用于：

- 解锁复习挑战
- 购买连续保护卡
- 更换界面主题
- 解锁额外练习

MVP 阶段可以只展示宝石，不做商店。

### 4.5 每日任务

每天给 3 个小任务：

- 完成 1 节课
- 答对 5 道听音题
- 复习 3 个错题

奖励：

- 经验值
- 宝石
- 连续学习保护

## 5. 题型原型

### 5.1 听音选字

播放音频，用户选择正确传统蒙古文字母。选项内蒙古文字母竖排居中显示。

状态：

- 答对：绿色反馈、获得 XP
- 答错：扣红心、显示正确答案、加入错题

### 5.2 看图选词

展示图片，选择对应蒙古文。词汇选项必须竖排，不能横向排成一行。

用于：

- 家庭
- 动物
- 数字
- 食物

### 5.3 拼字补全

展示缺失字母的蒙古文词，用户从候选字母中补全。缺字词也按竖排展示。

用于训练：

- 字母形态
- 字母连接
- 词首、词中、词尾差异

### 5.4 配对题

把中文、蒙古文和音频配对。

用于复习。

### 5.5 单元挑战

混合题型，红心更少，奖励更高。

## 6. 页面清单

### 6.1 启动页

展示产品名、学习目标和开始按钮。

建议风格：

- 明亮
- 活泼
- 大按钮
- 不使用动物导师

### 6.2 课程路径页

核心页面。

结构：

```text
顶部状态栏
单元标题
课程路径
当前课程浮层
底部导航
```

### 6.3 课程开始页

展示：

- 课程名
- 本课学习内容
- 可获得 XP
- 当前红心
- 开始按钮

### 6.4 答题页

展示：

- 顶部进度
- 红心
- 题干
- 音频按钮
- 选项
- 确认按钮

### 6.5 答题反馈页

答对：

- 显示“正确”
- 显示获得 XP
- 继续按钮

答错：

- 显示“再试一次”
- 显示正确答案
- 扣 1 红心
- 加入错题

### 6.6 课程完成页

展示：

- 本课 XP
- 正确率
- 剩余红心
- 新词数量
- 是否保持连续学习

### 6.7 每日任务页

展示三个任务和完成进度。

### 6.8 排行页

如果只是自己玩，可以做本地排行榜：

- 今天 XP
- 本周 XP
- 历史最好记录

不需要联网。

### 6.9 练习页

功能：

- 恢复红心
- 错题复习
- 听音专项
- 字母专项
- 词汇专项

## 7. 视觉方案

为了更接近强游戏化学习，但避免直接复制，建议使用：

| 角色 | 方案 |
| --- | --- |
| 主色 | 草原蓝 `#2E8CCF` |
| 辅色 | 日光黄 `#F5B93F` |
| 正确 | 青绿 `#19A974` |
| 错误 | 珊瑚红 `#EF5B4C` |
| 背景 | 云白 `#F5F8FB` |
| 文字 | 深墨蓝 `#1F2A37` |

形象方向：

- 不做动物导师
- 可以使用“字母精灵”或“印章徽记”
- 也可以完全不做角色，只用图标和徽章

## 10. MVP 取舍

可以先做：

- 课程路径
- 红心
- XP
- 宝石
- 连续学习
- 每日任务
- 错题复习
- 本地排行榜

暂时不做：

- 联网排行榜
- 付费恢复红心
- 好友系统
- 复杂商城
- AI 语音评分

## 11. 开发优先级

1. 本地课程数据
2. 课程路径页
3. 答题页
4. 答题反馈
5. 红心和 XP
6. 课程完成页
7. 每日任务
8. 练习恢复红心
9. 本地排行榜
